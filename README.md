# SP Tech Zone – Telegram SMM Bot

Telegram বট, যার মাধ্যমে ইউজার ব্যালেন্স দিয়ে Telegram Views ও Members অর্ডার দিতে পারে।

|---|---|
| GitHub রিপোজিটরি | https://github.com/playoints14-hue/sp-smm-bot |
| Render (লাইভ সার্ভার) | https://sp-smm-bot.onrender.com |

## ফাইল

| ফাইল | কাজ |
|---|---|
| `bot.py` | বটের মূল কোড: মেনু, অর্ডার, ব্যালেন্স, রিডিম কোড, অ্যাডমিন কমান্ড |
| `run.py` | সার্ভার সচল রাখে (keep-alive) ও বট ক্র্যাশ করলে আবার চালু করে |
| `requirements.txt` | প্রয়োজনীয় Python লাইব্রেরি |
| `.gitignore` | গোপন ফাইল ও ডাটাবেস GitHub-এ যেতে বাধা দেয় |

## Render সেটিংস

- **Service type:** Web Service
- **Runtime:** Python 3
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `python run.py`
- **Environment Variable:** `PYTHON_VERSION` = `3.12.8`

## Environment Variables (Render)

শুধু এই চারটি লাগবে। বাকি সব সেটিং বটের অ্যাডমিন প্যানেল (`/admin`) থেকে করা হয়:

- `BOT_TOKEN`
- `ADMIN_ID`
- `PANEL_API_URL`
- `PANEL_API_KEY`

এছাড়া Render-এর Python সংস্করণের জন্য `PYTHON_VERSION` = `3.12.8` যোগ করুন।

## সতর্কতা

Telegram-এ ভিউ ও মেম্বার বিক্রির ক্ষেত্রে অ্যাকাউন্ট বা চ্যানেল সীমিত হওয়ার ঝুঁকি আছে। বিষয়টি বিবেচনায় রাখুন।


## অ্যাডমিন প্যানেল থেকে প্রথম সেটআপ

১. বটে `/admin` লিখুন।
২. **📣 চ্যানেল** → **📢 চ্যানেল ১** → `@smspanelprirvitesp` (সকল ইউজারের চ্যানেল, হিডেন লিংকসহ অর্ডার)।
৩. **📣 চ্যানেল** → **🔒 চ্যানেল ২** → `@SP_ORDER_UPDATE` (শুধু অ্যাডমিনের, পূর্ণ বিবরণ)।
৪. **📣 চ্যানেল** → **🔐 জয়েন চ্যানেল** → `@smspanelprirvitesp` (বট ব্যবহারের আগে বাধ্যতামূলক জয়েন)।
৫. প্রতিটি চ্যানেলে বটকে **অ্যাডমিন** বানান (মেসেজ পাঠানোর অনুমতিসহ)।
৬. **🛍 সার্ভিস** → **➕ নতুন ক্যাটাগরি** → নাম লিখুন (যেমন `Telegram`)। রিফিল অন/অফ বেছে নিন। লোগো নিজে থেকে তৈরি হবে।
৭. ক্যাটাগরির ভেতর থেকে **➕ এখানে সার্ভিস যোগ** দিয়ে সার্ভিস যোগ করুন।

> চ্যানেল যোগ করার আগে বটকে সেই চ্যানেলে অ্যাডমিন না বানালে বট সেটি গ্রহণ করবে না।

## সমস্যা হলে

- **চ্যানেলে বার্তা যাচ্ছে না:** অ্যাডমিন প্যানেল → 📣 চ্যানেল → 🧪 চ্যানেল পরীক্ষা। কোন চ্যানেলে কেন যাচ্ছে না তা দেখাবে।
- **ব্যবহারকারী "সমস্যা হয়েছে" দেখলে:** কারণ সহ একটি বার্তা অ্যাডমিনের কাছে যাবে।
