# SP Tech Zone – Telegram SMM Bot

Telegram বট, যার মাধ্যমে ইউজার ব্যালেন্স দিয়ে Telegram Views ও Members অর্ডার দিতে পারে।
ইউজার বাংলা বা ইংরেজি ভাষা বেছে নিতে পারে। অ্যাডমিন প্যানেল বাংলায়।

## স্থায়ী চ্যানেল (কোডে বসানো)

| চ্যানেল | কাজ |
|---|---|
| `@smspanelprirvitesp` | চ্যানেল ১: সকল ইউজার। বট স্টার্টে বাধ্যতামূলক জয়েন। অর্ডার পোস্ট: অর্ডার নম্বর, ক্রেতা, ক্যাটাগরি, সার্ভিস, লিংক, কোয়ান্টিটি, খরচ, সময় |
| `@SP_ORDER_UPDATE` | চ্যানেল ২: শুধু অ্যাডমিন। পূর্ণ বিবরণ: ইউজারনেম/আইডি, প্যানেল অর্ডার আইডি, সার্ভিস আইডি, লিংক, ব্যালেন্স |

এই দুটি চ্যানেল `config.py`-তে স্থায়ীভাবে বসানো আছে। অ্যাডমিন প্যানেল → 📣 চ্যানেল থেকে পরে বদলানো যাবে।
চ্যানেলে বটকে অ্যাডমিন বানাতে হবে (মেসেজ পাঠানোর অনুমতিসহ)।

## ফাইল

| ফাইল | কাজ |
|---|---|
| `bot.py` | বটের মূল কোড: মেনু, ভাষা, অর্ডার, ব্যালেন্স, রিডিম কোড, অ্যাডমিন প্যানেল |
| `config.py` | Environment Variable, স্থায়ী চ্যানেল, ক্যাটাগরি ইমোজি ও ইমোজি পিকার তালিকা |
| `i18n.py` | ইউজারের বাংলা ও ইংরেজি সব লেখা |
| `db.py` | ডাটাবেস: ইউজার, ক্যাটাগরি, সার্ভিস, অর্ডার, ট্রানজ্যাকশন, রিডিম কোড |
| `logo.py` | ক্যাটাগরির নাম থেকে স্বয়ংক্রিয় ব্র্যান্ড লোগো (Telegram, Facebook, Instagram ইত্যাদি) |
| `run.py` | সার্ভার সচল রাখে (keep-alive) ও বট ক্র্যাশ করলে আবার চালু করে |
| `requirements.txt` | প্রয়োজনীয় Python লাইব্রেরি |
| `.gitignore` | গোপন ফাইল ও ডাটাবেস GitHub-এ যেতে বাধা দেয় |

## Render সেটিংস

- **Service type:** Web Service
- **Runtime:** Python 3
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `python run.py`
- **Environment Variable:** `PYTHON_VERSION` = `3.12.8`

## Environment Variables (Render)

শুধু এই চারটি লাগবে। বাকি সব সেটিং বটের অ্যাডমিন প্যানেল (`/admin`) থেকে করা হয়:

- `BOT_TOKEN`
- `ADMIN_ID`
- `PANEL_API_URL`
- `PANEL_API_KEY`

## ইউজার ফ্লো

1. `/start` → প্রথমে চ্যানেলে জয়েন বাধ্যতামূলক। জয়েন ছাড়া বট চালু হবে না, চ্যানেল ছাড়লেও আবার জয়েন চাইবে।
2. জয়েনের পর ভাষা বেছে নিন: 🇧🇩 বাংলা / 🇬🇧 English। মেনু থেকে 🌐 Language দিয়ে পরেও বদলানো যাবে।
3. ক্যাটাগরি → সার্ভিস → লিংক → পরিমাণ → কনফার্ম। ব্যালেন্স থেকে মূল্য কাটা হবে।

## অ্যাডমিন প্যানেল থেকে প্রথম সেটআপ

১. বটে `/admin` লিখুন।
২. **🛍 সার্ভিস** → **➕ নতুন ক্যাটাগরি** → নাম লিখুন (যেমন `Telegram`)। লোগো ও ইমোজি নিজে থেকে তৈরি হবে। রিফিল অন/অফ বেছে নিন।
৩. ক্যাটাগরির ভেতর থেকে **➕ এখানে সার্ভিস যোগ** দিন। নাম, ইমোজি (পিকার থেকে), প্যানেল আইডি, মূল্য, সীমা লিখুন।

> প্যানেল আইডি সংখ্যায় দিন (যেমন `14759` বা `147.59`)। ইউজার এটি দেখবে না।

## সমস্যা হলে

- **চ্যানেলে বার্তা যাচ্ছে না:** অ্যাডমিন প্যানেল → 📣 চ্যানেল → 🧪 চ্যানেল পরীক্ষা। কোন চ্যানেলে কেন যাচ্ছে না তা দেখাবে।
- **ব্যবহারকারী "সমস্যা হয়েছে" দেখলে:** কারণ সহ একটি বার্তা অ্যাডমিনের কাছে যাবে।

## সতর্কতা

Telegram-এ ভিউ ও মেম্বার বিক্রির ক্ষেত্রে অ্যাকাউন্ট বা চ্যানেল সীমিত হওয়ার ঝুঁকি আছে। বিষয়টি বিবেচনায় রাখুন।

## ছবি ও ভয়েস (অ্যাডমিন প্যানেল)

প্রতিটি ফিচার-স্ক্রিনে আলাদা ছবি ও ভয়েস দেওয়া যায়।

1. `/admin` → ⚙️ সেটিং → 🖼 স্ক্রিন ছবি ও ভয়েস
2. স্ক্রিন বেছে নিন (ওয়েলকাম, জয়েন গেট, ভাষা, ভয়েস প্রশ্ন, মেনু, ক্যাটাগরি, সার্ভিস, পরিমাণ, সারাংশ, অর্ডার সফল, ব্যালেন্স, টাকা যোগ, আমার অর্ডার, অর্ডার বিবরণ, রিফিল, রিডিম, সেটিংস)
3. 🖼 ছবি দিন → একটি ছবি পাঠান। 🎙 ভয়েস দিন → একটি ভয়েস বার্তা (Voice note) বা অডিও পাঠান।
4. ক্যাটাগরি ও সার্ভিসের জন্যও আলাদা ভয়েস দেওয়া যায় (ক্যাটাগরির বিবরণ ও সার্ভিস ভয়েস থেকে)।

- ছবি না দিলে ডিফল্ট ব্র্যান্ড ছবি (`assets/brand.png`) দেখাবে। ক্যাটাগরি ও সার্ভিসের নিজের লোগো/ছবি থাকলে সেটিই আগে যাবে।
- ভয়েস শুধু তখনই যায় যখন ইউজার ভাষা বাছাইয়ের পর ভয়েস **চালু** রেখেছে। এটি সেটিংস থেকে যেকোনো সময় বদলানো যায়।
- ভয়েস বার্তা Telegram-এর Voice note (OGG/Opus) হিসেবে পাঠান। অডিও ফাইলও চলবে।
- স্বয়ংক্রিয় টেক্সট-টু-স্পিচ এই বটে নেই। প্রতিটি ভয়েস আপনাকে নিজে রেকর্ড করে দিতে হবে।
- ছবির ক্যাপশন ৯০০ অক্ষরের বেশি হলে ছবি আলাদা যায় এবং লেখা পরে আসে।
